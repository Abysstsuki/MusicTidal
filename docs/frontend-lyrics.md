# 歌词曲面与节奏动效

- `components/curvedlyrics.tsx` 保留 DOM 歌词作为布局、字体和无障碍内容；Three.js 模块只在有歌词时按需加载。
- `lib/lyric-scene.ts` 将实际字体与换行布局绘制成两张 CanvasTexture，贴到柱面网格。当前句放在独立缩放节点上，其他歌词和翻译另绘一层；大跳动时逐渐淡出相邻文字。镜头围绕当前句做固定半径的环绕，通过镜头偏移保留原来的屏幕位置，鼠标视角和节奏缩放分开更新。
- `lib/rhythm-config.json` 保存正式调试第一版的完整 Demo 配置，是检测参数与缩放参数的统一入口。本版使用 `rmsRise`：只由 30–250 Hz 的低频 RMS 增量起音；中高频权重为 0。`attackDelta = 0.16451`、`attackRatio = 0.5` 来自用户实际调试配置，不在播放时重新自动估算。
- `lib/rhythm-detector.ts` 使用 Meyda 5.6.3（MIT）提取 Hann 窗频谱和 RMS，按 Demo 的规则进行 20 ms 居中平滑，再与约 30 ms 前的低频 RMS 比较。增量必须达到 `max(0.16451, 噪声背景增量 × 4)`，相对增幅至少 50%，整体 RMS 必须高于 0.008。噪声背景以 600 ms 时间常数更新。
- 增量降到门限的 35% 以下并持续 15 ms 后恢复检测；候选峰顶最多跟踪 120 ms，下降 8% 并持续 15 ms 后确认。峰顶之间至少间隔 120 ms。所有有效触发都启动同样幅度的包络：峰值保持 45 ms，以速度 10 平滑回落，不做声音强弱分级。这仍是低频起音检测，不保证所有触发都是底鼓，也不识别曲风。
- `public/audio/rhythm-sampler.js` 使用 AudioWorklet 在音频线程采样：2048 点窗口、512 点步长、重叠窗口，每约 11–12 ms 取一帧（48/44.1 kHz）。Meyda 按需加载，在主线程提取频谱，渲染读取最新包络。
- `hooks/use-audio-rhythm.ts` 在浏览器允许 AudioContext 运行后，才连接媒体音源；分析分支输出静音，不处理或叠加原音频。暂停、切歌、跳转、页面隐藏时重置采样与统计，并丢弃旧消息。CORS 音频加载失败时播放器换回普通音频元素，不再分析该地址；AudioWorklet 不可用时保留播放与曲面效果。
- 媒体音源输出已包含播放器音量衰减，分析分支会先除以当前音量，恢复与 Demo 原始 PCM 相同的振幅，再送入 RMS 检测器。调节音量时重置采样窗口，避免旧音量与新音量混用造成误触发；静音或音量为 0 时停止检测。这个补偿仅作用于采样缓冲区，不改变听到的音量。

当前句缩放上限从 `rhythm-config.json` 的 `scale = 1.1` 读取，每次有效起音的峰值目标统一为 1.1 倍，随后按包络回到 1 倍，实际幅度只受动画平滑和播放状态影响，不按声音大小分级。缩放采用快速起音、较慢回落。保留轻微的慢速摇摆，强度受音频 RMS 影响。鼠标镜头使用横向 0.29、纵向 0.19 弧度的固定半径环绕，不改变观看距离。

正式播放需要等待平滑窗口后半段与峰后回落帧，确认后才从完整脉冲开始缩放；Demo 在确认后把事件时间回填到此前的峰顶，两者的视觉触发时刻有这个必要差异。在 48 kHz 下，20 ms 平滑会等待约 10.7 ms 的下一帧，15 ms 回落确认取整为两帧，另有达到 8% 回落所需的时间。采样与短窗口历史保持有界；暂停、跳转或切歌时会全部清空。配置中的旧 `peak*`、频谱阈值字段保留用于对照和导出，不参与本版起音触发；`timingOffset` 只供离线回填，本版为 0。

暂停后动画平缓停止；隐藏标签页停止渲染。纹理只在歌词、字体或尺寸变化时重绘；动画直接更新网格和镜头，不逐帧更新 React 状态。帧率上限 45 fps，舞台大小的帧缓冲像素密度上限 1.75，文字纹理密度上限 2，二者边长均限制为 2048。触摸设备保留曲面和节奏，关闭鼠标视角跟随。

WebGL 不可用、上下文丢失、减少动态效果或强制颜色模式下显示原生 DOM 歌词。`?preview=1` 没有真实音频，播放按钮驱动专用于视觉预览的演示节奏；真实房间只读取播放音频。

开发模式添加 `?lyricsDebug=1`，控制台会输出 `[lyrics-motion]` 的实际脉冲、缩放、目标缩放和镜头角度，以及 `[rhythm-detection]` 的采样率、每秒最大 RMS/增量、当前门限和候选状态，用于区分未采样、增量不足与触发后渲染问题；生产模式不输出。
