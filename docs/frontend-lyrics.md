# 歌词曲面与节奏动效

- `components/curvedlyrics.tsx` 保留 DOM 歌词作为布局、字体和无障碍内容；Three.js 模块只在有歌词时按需加载。
- `lib/lyric-scene.ts` 将实际字体与换行布局绘制成两张 CanvasTexture，贴到柱面网格。当前句放在独立缩放节点上，其他歌词和翻译另绘一层；大跳动时逐渐淡出相邻文字。镜头围绕当前句做固定半径的环绕，通过镜头偏移保留原来的屏幕位置，鼠标视角和节奏缩放分开更新。
- `lib/rhythm-detector.ts` 使用 Meyda 5.6.3（MIT）提取 Hann 窗频谱和 RMS，恢复 30–250、250–2000、2000–6500 Hz 的多频段正向频谱变化与音量起音检测，各频段权重为 1、0.9、0.55。自适应阈值、弱频段能量门限和高频降权减少噪声触发，保留低频、中频冲击响应；没有底鼓专用的能量比例、音高下滑或衰减确认筛选。
- 所有有效起音都触发相同幅度的包络：至少间隔 110 ms、峰值保持 45 ms，再平滑回落。取消声音强弱分级和“大覆盖小”，达到间隔条件的起音可以直接重启包络。它是音频冲击检测，不保证所有触发都是鼓点，也不识别曲风。
- `public/audio/rhythm-sampler.js` 使用 AudioWorklet 在音频线程采样：2048 点窗口、512 点步长、重叠窗口，每约 11–12 ms 取一帧（48/44.1 kHz）。Meyda 按需加载，在主线程提取频谱，渲染读取最新包络。
- `hooks/use-audio-rhythm.ts` 在浏览器允许 AudioContext 运行后，才连接媒体音源；分析分支输出静音，不处理或叠加原音频。暂停、切歌、跳转、页面隐藏时重置采样与统计，并丢弃旧消息。CORS 音频加载失败时播放器换回普通音频元素，不再分析该地址；AudioWorklet 不可用时保留播放与曲面效果。

当前句缩放上限为 `MAX_LYRIC_SCALE = 1.3`，每次有效起音的峰值目标统一为 1.3 倍，随后按包络回到 1 倍，实际幅度只受动画平滑和播放状态影响，不按声音大小分级。缩放采用快速起音、较慢回落。保留轻微的慢速摇摆，强度受音频 RMS 影响。鼠标镜头使用横向 0.29、纵向 0.19 弧度的固定半径环绕，不改变观看距离。

暂停后动画平缓停止；隐藏标签页停止渲染。纹理只在歌词、字体或尺寸变化时重绘；动画直接更新网格和镜头，不逐帧更新 React 状态。帧率上限 45 fps，舞台大小的帧缓冲像素密度上限 1.75，文字纹理密度上限 2，二者边长均限制为 2048。触摸设备保留曲面和节奏，关闭鼠标视角跟随。

WebGL 不可用、上下文丢失、减少动态效果或强制颜色模式下显示原生 DOM 歌词。`?preview=1` 没有真实音频，播放按钮驱动专用于视觉预览的演示节奏；真实房间只读取播放音频。

开发模式添加 `?lyricsDebug=1`，控制台会输出 `[lyrics-motion]` 的实际脉冲、缩放、目标缩放和镜头角度，用于检查鼠标移动时节奏是否仍持续；生产模式不输出。
